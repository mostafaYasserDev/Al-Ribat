## 📌 عن التطبيق
**الرباط** ليس مجرد تطبيق مهام تقليدي، بل هو أداة تساعدك على إعادة هيكلة يومك ليكون متمركزاً حول أوقات الصلاة. تدور فلسفة التطبيق حول تقسيم اليوم إلى فترات زمنية بين الصلوات الخمس، مما يجعلك تنجز عاداتك ومهامك بتنظيم يتوافق مع طبيعة يومك.

## ✨ المميزات الرئيسية
- 🕌 **الصلوات هي المحور:** ربط المهام والعادات بالفترات بين أوقات الصلاة المختلفة.
- 🎯 **جلسات التركيز:** أداة مدمجة لمساعدتك على إنجاز مهامك بتركيز عالٍ بدون تشتت.
- 📊 **إحصائيات وتقارير:** تتبع أداءك ومدى التزامك بشكل أسبوعي وشهري برؤى تحليلية مفيدة.
- 📖 **مكتبة عادات جاهزة:** قوالب ذكية جاهزة لمختلف العادات (دينية، تطوير الذات، الصحة، وغيرها).
- 🧠 **الحالة المزاجية:** سجل حالتك المزاجية وأضف تأملاتك وملاحظاتك اليومية.
- ☁️ **المزامنة والنسخ الاحتياطي:** دعم لحفظ البيانات واستعادتها بسلاسة.
